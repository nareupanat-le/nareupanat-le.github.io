📖 สรุปสูตรและหลักการสำคัญของระบบพิกัดเชิงขั้ว

ในระบบพิกัดเชิงขั้ว ระนาบจะถูกกำหนดด้วย จุดขั้ว (Pole) เทียบเท่ากับจุดกำเนิด $(0, 0)$ และ แกนเชิงขั้ว (Polar Axis) ซึ่งเทียบเท่ากับแกน $X$ ฝั่งบวก พิกัดระบุด้วย $(r, \theta)$ ในหน่วยเรเดียน โดยที่:

  • $r$ คือระยะทางเชิงทิศทางจากจุดกำเนิดไปยังจุดนั้น (รัศมีสามารถติดลบได้)
  • $\theta$ คือมุมที่ทำกับแกนเชิงขั้ว (วัดทวนเข็มนาฬิกาเป็นบวก, ตามเข็มนาฬิกาเป็นลบ) ในหน่วยเรเดียน
1. สูตรการแปลงพิกัด (Coordinate Conversion)
การแปลง สูตรคำนวณ ข้อสังเกตและข้อควรระวัง
จาก $(r, \theta) \to (x, y)$ $$x = r\cos\theta$$ $$y = r\sin\theta$$ คำนวณได้โดยตรงเสมอ ไม่ว่า $r$ หรือ $\theta$ จะเป็นค่าใด
จาก $(x, y) \to (r, \theta)$ $$r = \pm\sqrt{x^2 + y^2}$$ $$\tan\theta = \frac{y}{x} \quad (x \neq 0)$$ ต้องพิจารณา Quadrant ของจุด $(x, y)$ ร่วมด้วย เพื่อเลือกมุม $\theta$ ในหน่วยเรเดียนให้ถูกต้อง
2. การเลือกมุม $\theta$ ตามควอดรันต์ (Quadrant Rules ในหน่วยเรเดียน)
ฟังก์ชัน $\arctan(y/x)$ จะให้ค่ามุมในช่วง $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ เท่านั้น ดังนั้น:
  • Quadrant I ($x > 0, y > 0$): $\theta = \arctan\left(\frac{y}{x}\right)$
  • Quadrant II ($x < 0, y > 0$): $\theta = \arctan\left(\frac{y}{x}\right) + \pi$
  • Quadrant III ($x < 0, y < 0$): $\theta = \arctan\left(\frac{y}{x}\right) + \pi$
  • Quadrant IV ($x > 0, y < 0$): $\theta = \arctan\left(\frac{y}{x}\right) + 2\pi$
  • กรณีบนแกน: ถ้า $x=0, y>0 \implies \theta = \frac{\pi}{2}$, ถ้า $x=0, y<0 \implies \theta = \frac{3\pi}{2}$
3. ความไม่เป็นหนึ่งเดียวของพิกัดเชิงขั้ว (Non-Uniqueness)

ต่างจากพิกัดฉากที่มีคู่ลำดับเดียว จุดหนึ่งจุดในพิกัดเชิงขั้วสามารถแทนด้วยพิกัดได้นับไม่ถ้วน:

$$(r, \theta) = (r, \theta + 2k\pi) = (-r, \theta + (2k+1)\pi) \quad \text{เมื่อ } k \in \mathbb{Z}$$

ความหมายของ $r < 0$: หากกำหนด $r = -3, \theta = \frac{\pi}{4}$ หมายถึงให้หันหน้าไปในทิศมุม $\frac{\pi}{4}$ แล้ว ก้าวถอยหลัง ไป 3 หน่วย ซึ่งจะไปตกอยู่ที่ทิศทางของมุม $\frac{\pi}{4} + \pi = \frac{5\pi}{4}$ นั่นเอง
